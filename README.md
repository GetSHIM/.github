# .github

Organization profile and default community health files for
[GetSHIM](https://github.com/GetSHIM).

- `profile/README.md` renders on <https://github.com/GetSHIM>.
- `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, the issue forms and
  the pull request template are defaults. Any repository in the organization
  that does not ship its own copy inherits these.

A repository's own file always wins. If you are changing something for one
project, change it there, not here.
